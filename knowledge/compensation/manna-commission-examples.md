# Manna Snack Bars — Fernando Commission Examples

## Purpose

This file gives simple rounded commission examples for Fernando's Manna Snack Bars event sales.

The examples are for internal reference only and are easy to update manually.

## Important Notes

- Numbers are rounded.
- Commission is calculated only on the main bar price before tax.
- Add-ons and extras are excluded from standard commission.
- If official pricing changes, this table must be updated.
- Do not add future bonus systems here unless specifically approved.

| Stage | Monthly Valid Sales Count | Events <= $430 | Events > $430 |

## Example Reading Guide

If an event has an official event price of `$540`, a main bar price before tax of `$499`, and Fernando is in Stage 2 for the period, the rounded commission reference is `$50`.
